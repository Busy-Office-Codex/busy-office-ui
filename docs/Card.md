Container block for displaying a piece of record/view state (e.g. a dashboard tile). `selected` shows an accent border ring; `disabled` mutes the background and fades content; pass `onClick` to make it interactive (adds hover elevation and pointer cursor automatically).

```jsx
<Card>
  <Text variant="title">Open orders</Text>
  <Text variant="heading">128</Text>
  <Text variant="caption">+12 this week</Text>
</Card>
```
